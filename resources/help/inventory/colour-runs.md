Colour varies between production runs of pavers, block and stone. Tracking colour runs keeps each delivery separate so a customer's job comes from one run.

## Turn it on

Tick **Tracked by colour run** on the product. Each delivery you receive becomes its own run.

## How runs are used

- **Receiving**: enter the run from the pallet tag. See [Purchase orders and receiving](/help/inventory/purchase-orders).
- **Stock**: shows one row per run, with on-hand for each.
- **Picking**: every order ships from one run. The kiosk picks the run with the most on hand at that yard, so a whole order can come from it.
- **Transfers**: stock stays in its run when it moves between yards.

> **Tip** When a contractor comes back for more of the same job, check how much is left in the run before you confirm, and call them if it's running low.
