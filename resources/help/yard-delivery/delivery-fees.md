Choose how you charge for material deliveries under **Settings → Delivery → Delivery fees**. Staff can still set a fee by hand on any order.

## Charge by

| Method       | How the fee is worked out                                                         | Set up                                 |
| ------------ | --------------------------------------------------------------------------------- | -------------------------------------- |
| By zone      | A flat fee for the zone the delivery postal code is in                            | Add your **Delivery zones**            |
| By distance  | A **Base fee** plus a rate **Per km from the yard**                               | Staff enter the distance on each order |
| By truckload | A fee **Per truckload**, with the number of loads worked out from product weights | Set what **A load is up to (t)**       |

For truckload pricing to work, give each product a **Weight per base unit**. See [Adding a product](/help/products-pricing/add-a-product).

## Delivery zones

Zones match on postal code prefix, using the longest match. For example, a zone for `L8` and another for `L8P` lets you charge downtown differently from the rest of the city.

Zones are used for material deliveries and for rental drop-offs and pickups. For addresses outside every zone, set an **Outside every zone** fee, or leave it blank to set the fee by hand on those orders.

## On the order

The fee is calculated when the order is saved and shown as **Delivery fee**. Type over it to change it for that order.
