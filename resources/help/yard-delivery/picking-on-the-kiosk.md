The yard kiosk is the pick list on a tablet or phone. Sign in on the device, open **Orders and picking**, choose the order and select **Open on picker**.

## Pick each line

Each line shows the product, the bin to pull from, the colour run to ship from, and how it's measured:

- **Counted items** (pallets, bags, each): enter the **Quantity loaded**.
- **Weighed material** (anything sold by the tonne or set to truck scale weight): load it with the loader, weigh it, and enter the **Scale reading (net)**.
- **Loader buckets**: the line shows how many buckets to load.

Select **Picked** to confirm the line. A quantity within 5% of what was ordered counts as complete, so a scale reading of 9.7 tonnes on a 10-tonne order is fine.

If you can't load it all, select **Short or substitute**. See [Short picks and partial shipments](/help/yard-delivery/short-picks).

## Finish the load

When every line is done:

- For a delivery, select **Mark loaded**. It goes to the [dispatch board](/help/yard-delivery/dispatch-board).
- For a pickup, select **Ready for pickup**. It waits at the yard for the customer.

Stock comes off when the load is marked, by what was actually picked, and pallet deposits are counted out at the same time.

> **Tip** Colour-run products ship from a single run, so a job's pavers all match. The kiosk tells you which run to pull from.
